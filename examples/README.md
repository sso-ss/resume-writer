# Fictional resume example

[Alex Example](Alex_Example_Resume.md) is a fictional Senior Product Designer created with the repository's resume-writing skill to demonstrate its writing guidance and Editorial template with 10.5 pt body text. The name, location, employers, education, research, achievements, and metrics are invented for this demonstration. The email and portfolio use reserved example domains.

The sample targets B2B product design in general; it is not tailored to a real vacancy. It illustrates personal ownership, design decisions, collaboration, and the distinction between prototype findings and production results. Replace every demo claim and contact detail with verified personal information before using it for an application.

From the repository root, open the editable version with:

```sh
npx @sso_ss/resume-writer preview examples/Alex_Example_Resume.md --layout editorial-html
```

The review screenshot is captured from the real local app. The resume image is rendered from the verified one-page Editorial PDF. This sample keeps all text at least 10 pt; the skill allows a 9 pt minimum for secondary details. Two-column layouts are best for direct sharing; keep a single-column version for application portals, where column parsing varies. The start-page image shows the empty review form before a provider, resume, or job is selected.
